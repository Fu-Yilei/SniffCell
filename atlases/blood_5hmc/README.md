# Whole-blood modifiedC + 5mC + 5hmC catalog

[Download the compressed catalog](blood_universal.modifiedC_plus_5mc_5hmc.ctdmr.tsv.gz).
This GRCh38 catalog was used for all 34 whole-blood samples in the October 2026
SMaHT run. It has a shared class order of B-cell, Granulocyte, Monocyte, NK-cell,
and T-cell. Use this branch's scoring code, including its partial-profile
consensus handling, with this catalog.

| Component | Scoring rows |
|---|---:|
| Five-class modifiedC backbone | 90,216 |
| Added FANS 5mC | 15,025 |
| Added FANS 5hmC | 40 |
| Total | 105,281 |

There are 105,266 distinct genomic intervals: m and h can provide separate
scoring rows at the same interval. These counts are not counts of CpGs or cells.

## Reference and discovery

The modifiedC backbone was rebuilt from the original `all_celltypes_blocks`
reference with 5 B-cell, 3 Granulocyte, 3 Monocyte, 3 NK-cell, and 22 T-cell
profiles. Every eligible source block has at least two finite profiles per class.
Discovery uses a 0.40 methylation difference, one-block minimum, three-CpG
minimum, and 2,000-bp merge gap.

The additional channels use eight sorted PBMC samples: B, T, NK, and monocytes
from two donors. Every constituent block must have finite observations for all
four classes, effects in the same direction in both donors, each donor effect
at least 0.30, and median effect at least 0.40. The stable component contains
71,846 m and 48 h rows. Only rows outside the backbone's extraction intervals
are added, retaining 15,025 m and 40 h rows. All backbone scoring fields are
preserved. Source checksums and parameters are in [manifest.json](manifest.json).

## Missing granulocyte m/h profiles

The m/h rows explicitly set `unprofiled_celltypes=Granulocyte` and leave its
reference mean missing. A missing profile is not zero methylation.

- When complete modifiedC evidence excludes Granulocyte, read consensus combines
  the modifiedC and measured m/h evidence.
- When modifiedC leaves Granulocyte possible, or is mixed, that complete-profile
  result is preserved.
- With m/h evidence alone, compatible PBMC candidates retain Granulocyte as an
  unresolved possibility. Conflicting PBMC evidence cannot become a singleton
  Granulocyte call simply because its profile is missing.

`assay_consensus_rule` records the route in the read summary. Multiple labels
are valid candidate sets, not resolved single-cell identities. Granulocyte
subtypes and T/B subtypes are not separate classes. Support for unknown profiles
in this release is specifically implemented for Granulocyte in the shared blood
schema; it is not a general imputation method for arbitrary missing classes.

## Use and validation

```bash
sniffcell deconv -i sample.bam -r GRCh38.fa \
  -b atlases/blood_5hmc/blood_universal.modifiedC_plus_5mc_5hmc.ctdmr.tsv.gz \
  -o blood_assignments --bam-modification auto \
  --read_assignment_mode closest_reference_mean --per_read_min_agreement 0.66 -t 8
```

This invocation writes TSV outputs. BAM splitting requires an explicit
`--split_bam_groups` request; `--regions` also creates a subset BAM. Existing-call
annotation can use the same catalog via `sniffcell anno -b ...` and rescans the
original BAM. Use `--evidence_mode per_read` for readable labels based on
per-read consensus, as in production. The `all_rows` reporting mode describes
raw ctDMR evidence instead. An m-only input supplies no evidence at h-specific markers; the
meaning of the m signal still depends on the basecaller.

Both ONT and PacBio smoke checks passed. Eight bounded reciprocal-donor checks
used markers selected from the opposite donor, plus the independent modifiedC
backbone. The expected sorted class was compatible with 70.9–83.6% of nonmixed
marker-informative reads. This counts compatible multi-label calls. There is no
granulocyte FANS control, and these checks do not establish genome-wide accuracy
or superiority over the older PBMC catalog. All 34 production outputs passed
technical QC.

This branch update also makes per-read variant readable labels use the same
consensus as `assigned_code`. In the original production execution, numeric
consensus codes retained missing-profile candidates, but the separate readable
summary could use raw ctDMR codes and omit an unresolved class. Historical
readable annotation labels have not been regenerated by this catalog export.

The published TSV preserves every production scoring field. Only non-scoring
provenance changes: `atlas_source` uses basenames, and stale candidate-export
values of `paired_stability_filter`/`paired_donors` are corrected to `True`/`2`
on the FANS rows. The source-file checksum and a checksum over all unchanged
fields are recorded in the manifest. No read identifiers, BAMs, or callsets are
included. The exporter is `tools/export_smaht_atlases.py`.
