# SMaHT production catalogs, 2026-10-16

This GRCh38 release records the catalogs used for 407 completed SMaHT samples:
34 whole-blood and 373 non-blood samples. Read assignment and existing-call
annotation used the same catalog for each sample. All 407 passed technical
output QC; 405 had existing callsets to annotate. No BAM outputs were requested.

Choose a catalog by tissue. These files are alternatives to the original
precomputed catalogs; adding them does not silently change any CLI atlas choice.

production checksum; it is not the experimental nine-class annotation catalog.

## Differences from the original tissue catalogs

- Blood includes Granulocyte and adds separate FANS m/h evidence. The legacy
  PBMC catalog has only B, T, NK, and monocyte classes.
- Brain retains Neuron/Oligodendrocyte classes and adds m/h evidence. It does
  not add astrocytes or microglia.
- Lung has Alveolar-Endothelial, Alveolar-Epithelial, Alveolar-Macrophage,
  Bronchus-Epithelial, Bronchus-Smooth-Muscle, Interstitial-Macrophage, and Pleura.
  The older lung catalog has only the two epithelial and two macrophage classes.
- Each colon segment has Fibroblast, Macrophage, its corresponding Endocrine,
  and Epithelial classes. The older combined colon catalog contrasts left/right
  epithelium and lacks an endocrine class.
- Liver retains Endothelial, Hepatocyte, and Macrophage. Its intervals and means
  are nearly identical to the original `combined_dt04` liver catalog, although
  the class order and a small number of intervals/partitions differ.
- Aorta is Endothelial/Smooth-Muscle; heart is Cardiomyocyte/Fibroblast; skin is
  Dermal-Fibroblast/Epidermal-Keratinocyte. These limited schemas do not represent
  every compartment in those tissues.

Only blood and brain add separate m/h rows. The seven TSVs in this directory
use the legacy modifiedC path. They were generated from `all_celltypes_blocks`
with tissue-specific class definitions, difference threshold 0.40, minimum one
block and three CpGs, and maximum gap 2,000 bp. More rows or classes alone do
not establish better read-assignment accuracy; no matched-read comparison with
all original catalogs was performed.

## Provenance and reproducibility

[manifest.json](manifest.json) maps codes to files and gives row counts, schemas,
assays, and checksums. The seven tissue TSVs are compressed losslessly: their
decompressed bytes exactly match the original execution inputs. The blood
export changes only the provenance fields documented in its own manifest.
The existing brain artifact is byte-identical to the one used in production.

The production base was commit `26e0ad9f6b5ebfd853910feacc9fa50037872861`, with
two execution fixes now included here:

1. Wholly unobserved CpG columns are excluded from read means in all assays;
   partially observed columns retain the existing imputation. This prevents
   NaN distances from defaulting to the other reference group.
2. Whole-blood consensus explicitly handles missing granulocyte m/h profiles.

The update additionally fixes per-read variant readable summaries to use those
consensus codes, rather than the original row votes. This corrects possible
disagreement between a numeric assignment and its readable labels, and excludes
mixed reads from per-read label summaries. Existing production outputs are
preserved; their readable annotation tables were not regenerated by this export.

To reproduce the packaging from authorized local artifacts:

```bash
python tools/export_smaht_atlases.py --smaht-root /path/to/SMaHT --atlas-root atlases
```

The exporter refuses to overwrite existing output files and checks the frozen
input hashes. It exports derived reference catalogs only. The files are separate
downloads, not part of the Python wheel.

Of the original 560-sample inventory, 146 remained outside this run pending
suitable esophagus, muscle, testis, adrenal, and ovary catalogs; seven fibroblast
controls were also not submitted. Technical completion is conditional on the
listed schemas and does not establish full tissue representation.
